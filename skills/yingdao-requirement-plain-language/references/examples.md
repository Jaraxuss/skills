# 课堂提需示例

示例来自湖南益丰案例的表达方式，用于校准语气和信息量；其他客户的文件名、字段、规则与输出边界必须从其实际材料确定。这里不保存客户账号、内部编码和本地路径。

## 网站下载和表格整理

前提：教练已确认主流程，实际提供网站配置与规则表、原始导出样例、空白输出模板。旧台账中跨商业归属的备注已排除。客户最终人工导入内部系统。

```text
帮我做一个网载流向流程：从供应商网站下载配送记录，按规则筛选，再整理成标准表。

我会提供客户配置表、网站导出样例和标准模板。配置表里有网址、账号和“整理说明”。开始日期、结束日期、归属年月和保存目录，每次运行时由我填写。

1. 登录网站，进入“供应商查询→配送记录”，按日期查询并导出。网站不能跨月查，跨月就按月分开下载，再合并明细。原表第三行起才是数据。
2. 按“整理说明”，根据公司名和门店编码筛选，注意区分“只保留”和“删除”；上海还要去掉品名含“黄葵”的记录。没写到的公司名先提醒我，不要自行处理。
3. 把门店名称填到终端客户，通用名填到产品，配送日期填到销售日期，配送批号填到批号，配送数量填到数量，规格和单位直接对应。负数照常保留。
4. 出入库标志填1，出入库类型填“二级”，商业客户编码和名称取配置表，行号从1递增。终端客户编码、业务员编码、业务员、产品编码留空。
5. 保存为“102_商业客户编码_归属年月_B_级别数字.xlsx”，保留原始下载文件。内部系统导入由我们人工做。

先用样例把表格整理跑通，再接网站下载。
```

例子把长篇规则放在真实提供的“整理说明”中，但将空白模板无法表达的固定值和文件名写在正文里。其他案例如果已有可读取的配置或范例完整承载这些约定，可进一步省略；不能让助手猜测。

## 一项关键规则的表达取舍

内部可能已分析到：原始明细包含正数和负数，未确认允许抵消，目标数量要与保留源行一致。

课堂写法可以是：“数量照原表填写，负数也保留，不要自行合并抵消。”不用带上数量平衡公式和验收用例。

内部可能已发现：规则附件没有覆盖部分公司名。

课堂写法可以是：“遇到规则表没写到的公司名，先列出来让我确认。”不能改成“其他都删除”，也不能只处理已覆盖记录后说全量完成。

## 简单事项不套长结构

已知业务只是将一个 Excel 的每位业务员数据分成独立文件，源表与字段均已核验，输出目录由人填写。无需复制网站案例的登录、日期分段和模板环节。

```text
帮我把这个销售明细按“业务员”拆成多个Excel，每个人一份，保留原表的列和每条记录，不做汇总。文件名用业务员姓名，输出目录运行时让我选。业务员为空的记录单独放一份，原文件保留。
```

这段中的空姓名处理必须来自本次确认；如未确认，改成“业务员为空时先提醒我”，不要借用示例替客户定规则。
