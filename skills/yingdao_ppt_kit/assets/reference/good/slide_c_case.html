案例 2：多表匹配，替代手工 VLOOKUP

大批量、多字段、要反复跑的匹配，交给 Pandas 更稳
业务问题

采购计划要人工 VLOOKUP 供应商主数据：字段多、耗时长，漏配很难被发现。

处理规则

按「供应商ID」左连接补齐名称、账期、类别；名称为空即判定未匹配。

输出结果

完整明细一张、未匹配清单一张，影刀接着做通知与归档。

match_orders.py 
import pandas as pd

orders = pd.read_excel("本周采购计划.xlsx")
master = pd.read_excel("供应商主数据.xlsx")

result = orders.merge(master, on="供应商ID", how="left")
unmatched = result[result["供应商名称"].isna()]

result.to_excel("完整采购计划表.xlsx", index=False)
unmatched.to_excel("未匹配清单.xlsx", index=False)
